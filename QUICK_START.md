# Quick Start: First 48 Hours

## Hour 1 — Pick the offer
- Open `01_strategy/offer_canvas.md`.
- Pick one niche.
- Write the paid pilot offer.
- Use the default $299 quick-win audit if stuck.

## Hours 2–4 — Build the prospect list
- Open `02_prospecting/prospecting_sop.md`.
- Add 50 companies to `02_prospecting/prospect_tracker.csv`.
- For each, write one issue and one suggested fix.

## Day 2 — Send the first 10
- Use `03_outreach/email_cadence.md`.
- Send Email 1 to 10 prospects.
- Send LinkedIn connection notes where possible.
- Track in the CSV/Notion.

## Rule
Do not edit the product for 48 hours. Send messages first.
