# SaaS $0→$5k Launch Kit

A sellable, execution-first launch kit for early-stage SaaS founders who need their first paid customers without ads, agencies, or complicated funnels.

## Promise
Use one narrow niche, one paid micro-offer, and a 50-prospect manual outreach sprint to book first calls and close first paid pilots in 30 days.

## Who this is for
- Solo SaaS founders
- Tiny B2B SaaS teams
- Productized service founders selling into SaaS
- Builders with a product/demo but no repeatable customer acquisition motion

## What is inside

### 01 Strategy
- `01_strategy/offer_canvas.md` — define niche, painful outcome, proof, price, guarantee.
- `01_strategy/icp_selector.md` — choose the highest-probability customer segment.
- `01_strategy/pricing_ladder.md` — free sample → paid pilot → implementation → retainer.

### 02 Prospecting
- `02_prospecting/prospecting_sop.md` — build the first 50-target list manually.
- `02_prospecting/site_scan_checklist.md` — 60-second scan to create a personalized hook.
- `02_prospecting/prospect_tracker.csv` — clean Notion/Sheets import template.

### 03 Outreach
- `03_outreach/email_cadence.md` — 5-touch cold email sequence.
- `03_outreach/linkedin_dm_cadence.md` — connection note + DM follow-ups.
- `03_outreach/personalization_bank.md` — fill-in-the-blank hooks and one-line fixes.
- `03_outreach/objection_responses.md` — replies to common objections.

### 04 Sales
- `04_sales/discovery_call_script.md` — 15-minute call script.
- `04_sales/audit_delivery_template.md` — paid/free audit deliverable template.
- `04_sales/paid_pilot_proposal.md` — $299/$799 pilot proposal template.

### 05 Delivery
- `05_delivery/three_day_delivery_sop.md` — deliver quick win fast.
- `05_delivery/testimonial_referral_script.md` — collect proof and referrals.
- `05_delivery/client_handoff.md` — wrap-up note and next-step upsell.

### 06 Launch Ops
- `06_launch_ops/30_day_calendar.md` — daily execution plan.
- `06_launch_ops/kpi_dashboard.md` — metrics and decision rules.
- `06_launch_ops/founder_daily_checklist.md` — 45-minute daily routine.

### 07 Assets
- `lead_magnet.md` / `lead_magnet.pdf` — free sample PDF.
- `landing_page.html` — simple static landing page.
- `pitch_deck_outline.md` — 1-page pitch outline.
- `launch_texts.md` — social/community launch posts.
- `prospects_send.csv` — current send-ready prospect list.

## How to use this kit
1. Fill `01_strategy/offer_canvas.md`.
2. Build 50 prospects using `02_prospecting/prospecting_sop.md`.
3. Send 10 prospects/day with `03_outreach/email_cadence.md`.
4. Book calls using `04_sales/discovery_call_script.md`.
5. Sell the paid pilot using `04_sales/paid_pilot_proposal.md`.
6. Deliver in 3 days using `05_delivery/three_day_delivery_sop.md`.
7. Track KPIs in `06_launch_ops/kpi_dashboard.md`.

## Default offer
**$299 Conversion Quick-Win Audit**
- 60-second video audit
- 3 conversion leaks
- 1 implemented quick fix or written implementation spec
- Delivered in 3 business days
- Upsell: $799 implementation sprint or $1,500/mo growth ops retainer

## Owner note
This kit is intentionally simple. Do not automate before first replies. Manual personalization creates the signal.
